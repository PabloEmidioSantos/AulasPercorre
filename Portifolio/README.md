# Portfólio — Pablo Emidio dos Santos

Portfólio pessoal responsivo, construído com HTML, CSS e JavaScript, sem dependências de back-end.

## Abrir

Abra o arquivo `index.html` no navegador ou use a extensão Live Server no VS Code.

## Personalizar

- Edite as informações pessoais e os três projetos em `index.html`.
- Ajuste paleta, animações e layout em `estilo.css`.
- O menu, as animações de entrada, a navegação ativa e o ano do rodapé são controlados por `roteiro.js`.
